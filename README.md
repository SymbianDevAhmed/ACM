# ACM

A collection of ACM and Competitive Programming training materials, problem solutions, projects, and reusable templates.

## Contents

- **Materials** — Training materials and Level 1 problems.
- **Projects** — Programming projects and practice work.
- **PrtSc** — Screenshots and problem-solving references.
- **Template** — Reusable programming templates.

## Purpose

This repository is used for practicing problem solving, improving programming skills, and organizing ACM training work and competitive programming resources.

## Languages & Tools

- C++
- Git & GitHub
- Visual Studio Code
